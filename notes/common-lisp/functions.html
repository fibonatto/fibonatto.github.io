Common Lisp Functions

Common Lisp Functions

1. Define a function

(defun square (x)
  (* x x))

(square 5) ; => 25

defun defines a named function. The function body contains forms evaluated in order, and the last form's values are returned.

2. Anonymous functions

(lambda (x) (* x x))

A lambda expression creates a function. Invoke it with funcall:

(funcall (lambda (x) (* x x)) 5) ; => 25

Use function or its shorthand #' to refer to a named function:

(defun double (x)
  (* x 2))

(funcall #'double 10) ; => 20

3. funcall and apply

funcall invokes a function with separately supplied arguments:

(funcall #'+ 1 2 3) ; => 6

apply takes its final arguments from a list:

(apply #'+ '(1 2 3)) ; => 6
(apply #'list 1 2 '(3 4)) ; => (1 2 3 4)

4. Optional, rest, and keyword parameters

(defun greet (name &optional (greeting "Hello"))
  (format nil "~a, ~a!" greeting name))

(greet "Ada")       ; => "Hello, Ada!"
(greet "Ada" "Hi")  ; => "Hi, Ada!"

&rest collects remaining positional arguments into a list:

(defun sum (&rest numbers)
  (apply #'+ numbers))

(sum 1 2 3 4) ; => 10

Keyword parameters are named at the call site:

(defun make-point (&key x y)
  (list x y))

(make-point :x 10 :y 20) ; => (10 20)

Defaults can be supplied for optional and keyword parameters:

(defun scale (x &key (factor 2))
  (* x factor))

(scale 5)             ; => 10
(scale 5 :factor 3)   ; => 15

5. Local functions with flet and labels

flet defines local functions. These local functions cannot recursively refer to one another through their local names.

(flet ((square (x) (* x x)))
  (square 4)) ; => 16

labels allows local functions to refer to themselves and to one another:

(labels ((factorial (n)
           (if (<= n 1)
               1
               (* n (factorial (1- n))))))
  (factorial 5)) ; => 120

6. Multiple return values

A function can return multiple values with values:

(defun divide-and-remainder (a b)
  (values (floor a b)))

Receive them with multiple-value-bind:

(multiple-value-bind (quotient remainder)
    (divide-and-remainder 17 5)
  (list quotient remainder)) ; => (3 2)

A normal single-value context generally uses the primary value.

7. Higher-order functions

Functions can accept other functions as arguments:

(defun map-one (function xs)
  (mapcar function xs))

(map-one #'1+ '(1 2 3)) ; => (2 3 4)

Common list-processing functions include:

(mapcar #'1+ '(1 2 3))                 ; => (2 3 4)
(remove-if #'oddp '(1 2 3 4))          ; => (2 4)
(remove-if-not #'evenp '(1 2 3 4))     ; => (2 4)
(find-if #'evenp '(1 3 4 5))            ; => 4
(reduce #'+ '(1 2 3 4))                 ; => 10

mapcar returns a new list. These functions do not require explicit recursive traversal for common list operations.

8. Function namespace

Common Lisp has separate namespaces for variables and functions:

(defun f (x)
  (+ x 1))

(let ((f 100))
  (list f (funcall #'f 2)))
; => (100 3)

Here, f refers to the local variable, while #'f refers to the function named f.

9. Recursion and iteration

A recursive implementation:

(defun sum-list (xs)
  (if (null xs)
      0
      (+ (car xs)
         (sum-list (cdr xs)))))

An iterative alternative:

(defun sum-list (xs)
  (loop for x in xs
        sum x))

Both are idiomatic tools. Use recursion when the recursive structure clarifies the algorithm; use iteration when it makes the implementation simpler.

10. Important distinction: functions and special forms

Ordinary function arguments are evaluated before the function is called:

(+ 1 2)

Special forms have their own evaluation rules. For example, if evaluates the condition and only the selected branch:

(if condition
    then-form
    else-form)

A function cannot reproduce this behavior merely by receiving both branches as ordinary arguments, because those arguments would be evaluated before the function call.

Quick reference

Form Purpose
defun Define a named function
lambda Create an anonymous function
#'name Refer to a function
funcall Call a function value
apply Call a function using a final list of arguments
&optional Declare optional positional parameters
&rest Collect remaining positional arguments
&key Declare keyword parameters
flet Define local functions
labels Define mutually recursive local functions
multiple-value-bind Bind multiple returned values
mapcar Map a function over lists
reduce Combine sequence elements
